# MOLAN Desktop Releases

This repository is dedicated to distributing MOLAN desktop releases.

It contains release notes, installation guidance, checksums, and downloadable
installers only. Source code and development history remain in the private
source repository:

- Source code: <https://github.com/rovdex-1/Nexora>
- Downloads: <https://github.com/rovdex-1/molan/releases>

Before installing a package, download `SHA256SUMS.txt` from the same release
and verify the package checksum. See [INSTALL.md](INSTALL.md) for platform
instructions.
